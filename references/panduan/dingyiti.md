# dingyiti — 定义题解题核心

## R (Resource / 资源)

**定义**: 定义题解题核心原则：识别被定义词，它代表被定义事物的最典型特征。

**核心要点**:
- **被定义词**: 定义名称，代表最典型特征
- **反对连连看**: 不做机械字面匹配
- **认知迁移**: 从抽象概念到具体案例

**三层心法**:
- **高度**: 跳出字面，把握本质
- **深度**: 深挖选项实质
- **细心**: 抓住主体、对象、特殊要求

**来源**: 定义课+判断总结。

## I (Intent / 触发)

**触发条件**:
- 定义判断题
- 被定义词晦涩抽象
- 用户在多个选项之间犹豫

**用户问法示例**:
- 「定义题怎么做」
- 「什么是被定义词」
- 「怎么排除错误选项」

## A1 (Application 1 / 标准应用)

**标准流程**:
1. **识别被定义词**: 看定义名称
2. **理解内涵**: 不只是字面，而是现实所指
3. **匹配选项**: 哪个选项最符合定义的核心特征
4. **排除陷阱**: 表面相似但实际不符的选项

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- 定义题独立，与其他逻辑题型关联较少

## E (Example / 示例)

**典型示例**: 被定义词=「车流模组」→ 核心是同向干扰

## B (Boundary / 边界)

**适用范围**: 定义判断题。
