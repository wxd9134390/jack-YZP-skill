# zhijie-genben-yuanyin — 直接根本原因因果链分析

## R (Resource / 资源)

**定义**: 直接根本原因题的因果链分析框架。核心规则：支持谁就让谁是根本原因，质疑谁就让谁是直接原因。

**题干结构**:
- **原观点**: A是原因
- **反对者**: B是原因
- **最终结果**: C

**因果链**:
```
支持原观点：A（根本原因）→ B（直接原因）→ C
支持反对者：B（根本原因）→ A（直接原因）→ C
质疑原观点：A（表面原因）→ ... → C（A不是根本原因）
质疑反对者：B（表面原因）→ ... → C（B不是根本原因）
```

**来源**: 逻辑2专项题型，套路固定。

## I (Intent / 触发)

**触发条件**:
- 题干出现「原观点」和「反对者」
- 题干涉及「根本原因」「直接原因」
- 问法含「质疑原观点」「支持原观点」

**用户问法示例**:
- 「直接根本原因题怎么解」
- 「支持谁让谁是根本原因」
- 「质疑反对者是什么意思」

## A1 (Application 1 / 标准应用)

**标准流程**:
1. **识别因果链**: 原观点 vs 反对者 vs 最终结果
2. **判断问法**: 支持/质疑原观点 or 支持/质疑反对者
3. **应用规则**:
   - 支持谁 → 让谁是根本原因
   - 质疑谁 → 让谁是直接/表面原因
4. **验证选项**: 看选项是否符合因果链逻辑

**标准示例**:

*示例1：质疑反对者*
> 题干：原观点说A导致C，反对者说B导致C。问质疑反对者。
>
> 分析：质疑反对者 → B是直接原因，A是根本原因 → A导致B → B导致C
> 正确选项：A是根本原因，它导致了B，B才导致C

*示例2：支持原观点*
> 题干：原观点说A导致C，反对者说B导致C。问支持原观点。
>
> 分析：支持原观点 → A是根本原因 → A导致B → B导致C
> 正确选项：A是根本原因，它导致了反对者的观点，反对者的观点才导致C

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- **vs 归因论证三段论**: 直接根本原因是归因论证的特殊子型，有固定套路。归因论证三段论是通用框架。

**变体场景**:
- 只有原观点没有反对者 → 不适用本框架，用归因论证三段论
- 因果链超过两环 → 需要识别哪两个是核心

## E (Example / 示例)

**典型示例**（来自课程）:
> 原观点：A导致C
> 反对者：B导致C
> 支持原观点 → A是根本原因 → A→B→C
> 质疑反对者 → B是直接原因，A是根本原因 → A→B→C

## B (Boundary / 边界)

**适用范围**: 直接根本原因题型（原观点vs反对者结构）。

**不适用场景**:
- 一般归因论证（用归因论证三段论）
- 无原观点/反对者的因果题

**常见错误**:
- 搞混支持/质疑对应的因果链方向
- 忽略因果链的多环结构
