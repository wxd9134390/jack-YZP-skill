# 题型分类解题框架 — 判断推理逻辑模块三层分类法

## R (Resource / 资源)

**定义**: 判断推理逻辑模块的三层分类法，题型决定解题路径。

**三层结构**:
1. **论证类**: 既有事实+分析原因，包括归因论证、一般质疑、一般支持
2. **推出类**: 必然性推理，包括假言命题、联言选言、模态命题等
3. **分析类**: 匹配题、排序题等

**来源**: 逻辑1-6+判断总结共8处提及，是判断推理的总纲。黄老师原话：「如果你能分得清题型，可能会做得更快更准。」

## I (Intent / 触发)

**触发条件**:
- 用户拿到逻辑判断题，不知道从哪入手
- 用户问「逻辑题有哪些类型」
- 用户在几种方法之间犹豫，不确定用哪个
- 用户复习时想系统梳理逻辑题型

**用户问法示例**:
- 「这道题是归因还是质疑」
- 「逻辑题怎么分类」
- 「什么是推出类」
- 「分析类有哪些」

## A1 (Application 1 / 标准应用)

**标准流程**:

**第一步：识别大类**
- 有「既成事实+原因分析」→ 论证类
- 有「如果...那么...」→ 推出类
- 有多个对象需要匹配/排序 → 分析类

**第二步：论证类细分**
- 有实验组+对照组 → 对比实验归因
- 有现在vs过去 → 时间对比归因
- 无对比 → 一般归因
- 问法含「质疑/削弱」→ 一般质疑（非归因）
- 问法含「支持/加强」→ 一般支持

**第三步：套用对应解法**
- 归因论证 → 归因论证三段论
- 一般质疑 → 一般质疑三段攻击
- 推出类 → 必然性推理规则
- 分析类 → 匹配/排序方法

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- **vs 归因论证三段论**: 题型分类是总纲，归因论证是其中一个子型的详细解法。
- **vs 一般质疑三段论**: 一般质疑是论证类的另一个子型，与归因论证并列。

**变体场景**:
- 题型识别模糊时 → 先用「有无论证」区分论证类vs推出类
- 论证类中「归因vs一般质疑」→ 看题干是否有「原因分析」结构

## E (Example / 示例)

**题型判断示例**:
> 「实验组用新疗法，对照组用旧疗法，实验组康复率高」
> → 对比实验归因 → 用归因论证三段论

> 「新研究证明模式A有效，因此将颠覆模式B」
> → 有论据有结论，但无原因分析 → 一般质疑 → 用三段攻击框架

## B (Boundary / 边界)

**适用范围**: 判断推理逻辑模块的所有题型识别。

**不适用场景**:
- 定义判断（属于独立模块）
- 类比推理（属于独立模块）
- 图形推理（属于独立模块）
