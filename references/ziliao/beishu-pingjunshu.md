## R (Resource / 资源)

**定义**：资料分析「平均倍数类」中的平均数与倍数两大块。平均数与比重**异曲同工**（都是分数，比重能考的平均数基本都能考）；倍数与增长率**可互换**（倍数−1=增长率，增长率+1=倍数）。

**核心关系**：
- 平均数 = 总量/个数（有单位：元/人、万吨/万亩）
- 倍数 = A/B（无单位）；1 倍 = 100%
- 换算：**是多少倍 = 多多少倍 + 1**；R = 倍数 − 1；倍数 = 1 + R

## I (Intent / 触发)

**触发条件**：
- 「平均」「人均」「每亩」「单位产量」「平均每场/每件/每笔」
- 「是……的几倍」「比……多几倍」「增长几倍」
- 「平均售价/单价高于上年同期的月份」→ 比值趋势
- 用户问「平均数增长率」「倍数和增长率换算」「基期平均数」

## A1 (Application 1 / 标准应用)

### 一、平均数五考点
1. **单个平均数**：总量÷个数。时间相关注意**闰年 366 天 / 平年 365 天**；闰年=能被 4 整除，整百年须被 400 整除（2000 闰、1900/2100 平）。
2. **两个平均数之比**：A/B ÷ C/D = **两边除中间** = (A×D)/(B×C)。若是 A÷B 比 C，给 C 补个 1 再两边除中间。
3. **基期平均数** = 基期比重公式 = 现期平均数 × (1+R2)/(1+R1)（分子增速 R1、分母增速 R2，即「溢价增长率反过来」）。
4. **平均数趋势 = 比值趋势**（同比重趋势）：分子增速 R1 > 分母增速 R2 → 上升；纯定性判断，不算数。
5. **平均数增长率 = 比值增长率**：R=(R1−R2)/(1+R2)。（比重不求增长率，平均数爱求）
6. **平均数之差 = 比值差**：见 `ronghe-zonghe.md`（不能秒杀，套公式）。

### 二、倍数五考法
- **最大坑：是多少倍 vs 多多少倍**（是多少 = 多多少 + 1）：
  - 我是你的 2 倍 = 比你多 1 倍；我是你的 10 倍 = 比你多 9 倍；我是你的 3.2 倍 = 多 2.2 倍
  - 我比你多 20% = 我是你的 1.2 倍
- **基期倍数** = 基期比重公式 = 现期倍数 × 溢价增长率（反过来）
- **比值倍数** = 比值增长率 + 1
- **间隔倍数** = 间隔增长率 + 1
- **翻番**：翻一番 ×2；翻 N 番 = 2^N 倍
- **基期环比增长率** = 基期倍数 − 1

### 三、差 vs 量（判读陷阱）
- 问「差」→ A 比 B，做减法
- 问「是多少/约多少」→ 问量，**别当差算**
- 单位：比值差→实际单位（元）；比值增长率→百分号

## A2 (Application 2 / 变体应用)

**相邻能力区分**：
- vs 比重类：基期平均数=基期比重、平均数趋势=比重趋势、平均数增长率=比值增长率；比重不求增长率。
- vs 年均：年均增长量/率见 `yunju-zengzhang.md`。
- vs 比较类：比大小用 `bijiao-lei.md`；求数值用本卡。

## E (Example / 示例)

*基期平均数*：23 年材料问 22 年平均每场服务人次 → 现期平均数 × (1+分母增速)/(1+分子增速)。
*比值趋势*：平均售价高于上年 ⇔ 销售额增速 R1 > 件数增速 R2。
*倍数坑*：进口是生产的 2.6 倍 → 比生产多 **1.6 倍**（不是 2.6 倍）。

## B (Boundary / 边界)

**常见错误**：
- 基期平均数/倍数用「溢价增长率」时用成正向（应反过来：(1+R2)/(1+R1)）。
- 平均数增长率分母写成 1+R1（应为 1+R2）。
- 是多少倍 / 多多少倍看错问法（年年挖坑）。

**不适用**：年均增长量/率（见 `yunju-zengzhang.md`）；纯比大小（见 `bijiao-lei.md`）。
