# abrx-core — ABRX四量与知二求二

## R (Resource / 资源)

**定义**: 资料分析的底层四量模型，所有公式的压缩表达。

**四量定义**:
- **A (基期值)**: 比较的基准时期，数值通常作为除数或减数。「比字后面的时期是基期」
- **B (限期值)**: 当前时期，数值通常作为被除数或被减数。B取「本」拼音首字母
- **X (增长量)**: 限期与基期的绝对差值，有单位。X是数学未知数
- **R (增长率)**: 限期与基期的相对差异，无单位，用百分数表示。R是比率通用符号

**核心关系（知二求二）**:
| 已知 | 求X | 求R | 求A | 求B |
|---|---|---|---|---|
| A,B | B-A | (B-A)/A = B/A - 1 | - | - |
| A,X | - | X/A | - | A+X |
| B,X | - | X/(B-X) | B-X | - |
| A,R | AR | - | - | A(1+R) |
| B,R | BR/(1+R) | - | B/(1+R) | - |
| X,R | - | - | X/R | X+X/R |

**来源**: 资料分析第0章 + 第1-7讲 + 资料总结。A和R的由来：基期用A是因为B前面的字母只有A；限期用B是因为「本」拼音首字母是B；X来自数学未知数；R是比率通用符号。

## I (Intent / 触发)

**触发条件**:
- 用户做资料分析题，已知两个量需要推导其他量
- 用户问「资料分析有哪些公式」
- 用户问「ABRX是什么」
- 用户问「知二求二怎么用」

**用户问法示例**:
- 「已知基期和增长率怎么求增长量」
- 「ABRX四量是什么关系」
- 「资料分析公式太多记不住怎么办」
- 「知道增长率和增长量怎么求基期」

## A1 (Application 1 / 标准应用)

**标准流程**:
1. **识别已知量**: 确认题目给了哪两个量（A/B/X/R中的两个）
2. **判断需求**: 确认需要求什么
3. **选择公式**: 从知二求二表中找到对应公式
4. **代入计算**: 代入数值，计算结果
5. **验证**: 快速心算验证结果是否合理

**标准示例**:

*示例1：已知A和R，求X*
> 题目：2025年某指标基期值为100，增长率为10%，求增长量。
>
> 分析：已知A=100，R=10%，需求X
> 公式：X = A×R = 100×10% = 10
> 答案：增长量为10

*示例2：已知B和R，求A和X*
> 题目：2025年某指标限期值为110，增长率为10%，求基期和增长量。
>
> 分析：已知B=110，R=10%
> 公式：A = B/(1+R) = 110/1.1 = 100
> 公式：X = B-A = 110-100 = 10
> 答案：基期为100，增长量为10

*示例3：已知X和R，求A和B*
> 题目：某指标增长量为20，增长率为25%，求基期和限期。
>
> 分析：已知X=20，R=25%
> 公式：A = X/R = 20/0.25 = 80
> 公式：B = A+X = 80+20 = 100
> 答案：基期为80，限期为100

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- **vs 速算方法选择树**: ABRX给出公式框架，速算方法选择树解决「怎么算得快」。两者经常同时使用：先用ABRX选公式，再用速算树选方法。
- **vs 增速比较原则**: ABRX负责四量推导，增速比较原则负责「问法判读」。遇到「增长最多/最快」时，先用判读原则确定问的是X还是R，再用ABRX公式计算。

**常见变体**:

*变体1：多个时间段的连锁应用*
> 2024→2025→2026，已知2024和2026的数值，求两年间总增长率。
> 处理：分别求两次增长量，再合成总增长量，最后计算总增长率。

*变体2：比重/倍数/平均数的ABRX应用*
> 资料分析的所有比重类、倍数类、平均数类题目，本质都是ABRX的变体。只要识别出哪个是A哪个是B，就可以套用四量关系。

## E (Example / 示例)

**典型示例**（来自课程）:
> 去年体重80kg，今年90kg，增量和增长率分别是多少？
> - 去年是基期 A=80，今年是限期 B=90
> - 增量 X = B-A = 10kg
> - 增长率 R = X/A = 10/80 = 12.5%

**边界示例**:
- **增速为负时**: A=100，R=-10%，则 B=90，X=-10
- **增速为零时**: A=B，X=0，R=0

## B (Boundary / 边界)

**适用范围**: 所有资料分析题型，只要涉及基期/限期/增长量/增长率，均可用ABRX框架。

**不适用场景**:
- 纯统计概念题（如同比环比的定义、百分数百分点的定义）——这些属于概念记忆，不需要ABRX
- 纯速算技巧题（如包子法计算1%）——ABRX给出公式，速算解决计算
- 极复杂的多步计算（如间隔增长率）——ABRX给出基础，复杂计算需要专项公式

**常见错误**:
- 记错公式方向（如把R=增长量/基期记成R=限期/基期）
- 混淆X和R的含义（X是增量，R是率）
- 忘记「知二求二」原则，试图死记所有公式变体

**与其他知识的关系**:
- 前置知识：初中数学的四则运算、百分数理解
- 后续扩展：速算方法选择树、415分数法、假设分配法
