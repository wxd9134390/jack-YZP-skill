# yunju-zengzhang — 年均增长量与年均增长率

> 来源：2026-10-28 补转 `20260702资料分析7（平均倍数类+第四章最后两道题）.mp4`（本讲新内容）。花生十三体系。

## R (Resource / 资源)

**定义**：资料分析「平均倍数类」章节的两大新考点——**年均增长量**与**年均增长率**。二者共同难点是**基期怎么选（推不推）**与**N 怎么定**。

**两个公式**：
- 年均增长量 = (末期 − 基期) ÷ N
- 年均增长率：末期/基期 = (1+R)^N

**核心铁律**：**N = 末期年份 − 基期年份，是算出来的，不是想出来的**。分子用了哪两年，分母就是那两年之差。

## I (Intent / 触发)

**触发条件**：
- 题干出现「年均增长量」「年均增量」「平均每年增加」
- 题干出现「年均增长率」「年均增速」「平均每年增长百分之几」
- 题干出现「十三五/十四五」「XX 年—XX 年年均」
- 用户问「基期要不要往前推」「N 是几年」

## A1 (Application 1 / 标准应用)

### 一、年均增长量
1. 找末期值、基期值（注意推不推）
2. N = 末期年份 − 基期年份
3. 年均增长量 = (末期 − 基期) ÷ N

### 二、年均增长率（三方法，按选项精度选）
1. **公式法**（选项离得远）：末期/基期 = (1+R)^N，代入试算或开方。
   - 例：比值 1.75、N=2 → (1+R)²=1.75；1.3²=1.69、1.4²=1.96，故 R 在 30%~40%，且靠近 30%。
2. **格尺法（格词法）**（选项近、N=4 尤其常用）：背 4 个锚点
   - **1.05⁴≈1.22 / 1.1⁴=1.46 / 1.15⁴=1.75 / 1.2⁴=2.07**
   - 中间值近似线性插值：1.46(10%) 到 1.75(15%) 分 5 格，每格 (1.75−1.46)/5≈0.06，对应 11%/12%/13%/14%。
   - 例：算出 1.51 → 1.46 是 10%，加 1 格 0.06=1.52 对应 11%，1.51 略小于 1.52 但远离 10% → 选约 11%。
3. **近似法**（R 极小，1% 级别）：末期/基期 ≈ 1+NR（忽略 R²、R³）。不准，兜底用。

## A2 (Application 2 / 变体应用)

**相邻能力区分**：
- vs 比值增长率：年均增长率是「几何平均」，用 (1+R)^N；比值增长率用 (R1−R2)/(1+R2)，两者不能混。
- vs 间隔增长率：间隔增长率是两期复利 R=R1+R2+R1R2；年均增长率是 N 期复利开 N 次方。

**衍生考点**：
- **年均增长率 + 间隔增长率混合**：给「两年平均增长率8.5%」→ 先算两年间隔增长率（8.5%+8.5%+0.7%≈17.7%）→ 再逆用求其中一年增速（R1=(R−R2)/(1+R2)）。
- **江苏特有：假设年均增速相同求后期**——用「年均增速相等」搭桥：25年/22年 = 22年/19年（两段年限相同且增速相同，比值必相等），直接求目标年，不必算 R。

## E (Example / 示例)

*示例1：年均增长量*
> 2016→2022，末期 377、基期 275。N=2022−2016=6。年均增量=(377−275)/6=102/6=17。

*示例2：格尺法*
> 末期/基期=1.51，N=4。1.1⁴=1.46(10%)、1.15⁴=1.75(15%)；每格 0.06。1.46+0.06=1.52≈11%，1.51 略低于 1.52 但远高于 1.46 → R≈11%。

*示例3：江苏搭桥*
> 20~22 年均增速 = 23~25 年均增速（相同）。则 25年/22年 = 22年/19年，直接求 25 年值，无需算 R。
