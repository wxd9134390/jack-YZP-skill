## A1 (Application 1 / 标准应用)

### 一、全章五模块框架（看山理论）
资料分析本质 = 一个数 + 比值 + 乘积 + 混合，万变不离其宗：
1. **ABRX（一个数/四量）**：今年(限期B)、去年(基期A)、增长量X、增长率R
2. **比重（特殊比值）**：现期/基期比重、比重趋势、比重差（单位百分点）、隔级比重
3. **平均数（特殊比值）**：现期/基期平均、平均趋势、平均差(=比值差)、平均增长率(=比值增长率)
4. **倍数（特殊比值）**：今年倍数、基期倍数、间隔倍数、翻番(2^N)；倍数增长率/差少考
5. **乘积（A×B）**：今年A×B、基期乘积、乘积增长率、乘积差(A×B−C×D)、乘积大小比较
- **盐水（混合）**：特殊计算技巧，不列方程直接解（3排序/已知3R求量比/已知2R量比求第3R）

### 二、各模块速记口诀
- **ABRX 四量 4 考点**（4343 记）：一般基期、间隔基期、多个基期(基期倍数/和差)、根据变化求后期
- **基期倍数/基期比重/基期平均** = 现期倍数 ×(1+R2)/(1+R1)（溢价增长率反过来）
- **比值增长率** R=(R1−R2)/(1+R2)；与**间隔增长率逆运用**公式相同（R1=(R−R2)/(1+R2)）
- **乘积增长率三情境**：有占比想乘积、有日均想乘积、有实际含义式子（总产量=单产×面积，总消费=人均消费×人数）
- **隔级比重**：小比大 = 小比中 × 中比大（小比中用除法）
- **饼状图**：12 点方向顺时针；盯 25%/50%（1/4、1/2）
- **比重差** = 今年的整体分之去年的部分 × 增长率之差；能秒杀（比重<1）
- **线段法三步**：划线标点→按比例分段→支点靠近分母量大的一边→计算
- **年均增长量** N = 末期年份 − 基期年份（写在分母左右一减）
- **格尺法锚点**：1.05⁴≈1.22 / 1.1⁴=1.46 / 1.15⁴=1.75 / 1.2⁴=2.07（可拓 5 次方：×1.1 即扩自身10%）

### 三、六大易错陷阱
1. **增长几倍 vs 是几倍**：增长/多几倍 = R；是/为几倍 = 1+R
2. **百分数 vs 百分点**：百分点是百分数差；比重差单位百分点（早年国考写百分号是出错，近年已改）
3. **降幅 vs 增速绝对值**：降幅仅当 R<0
4. **比值/平均数增长率分子分母**：(R1−R2)/(1+R2)，R1 是分子增速
5. **基期倍数/比重/平均用反**：乘 (1+分母增速)/(1+分子增速)
6. **翻番**：翻 N 番 = 2^N 倍（翻三番 = 8 倍，不是 3 倍）

### 四、年均增长量「推不推」五情况
- 给了就推；五年计划(十三五/十四五)必推；题干"17-20这四年"必推；图表让出第一年问后几年建议推
- 多个年份抽几年不一定推；推不了/顶格提问不推
- 本质：推才是常态，不推是早年不严谨的遗留

### 五、学习节奏（看山理论 + 刷题）
- **看山三境界**：看山是山（一道题一道题）→ 看山不是山（能分类）→ 看山是山（看穿本质共通）
- 课程 5 节半 ≈ 16-17 小时；再过一遍 + 背导图 + 速算课，约 10-15 小时可成体系
- **背熟标准**：考场紧张状态下也能脱口而出（磕磕巴巴 = 没背熟）；不急刷题，体系成型再刷

## E (Example / 示例)

*框架应用*：问「23 年是 21 年的几倍」→ 间隔倍数 = 间隔增长率 + 1。
*陷阱*：某量增 50%，「增长了几倍」答 0.5 倍（=R），不是 1.5 倍。
*学习*：第一套模考 70+、第二套 76-77，刷十几套后基本不错（老师当年经验）。
