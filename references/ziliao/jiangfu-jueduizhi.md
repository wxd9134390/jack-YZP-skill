# 降幅看绝对值原则 — 降幅计算规则

## R (Resource / 资源)

**定义**: 降幅=|增速|（仅当增速<0时）。降幅扩大/收窄的计算逻辑与增速不同。

**核心规则**:
- **降幅** = |增速|，仅当增速 < 0 时使用
- **增速扩大/缩小**：主体是增速本身
- **降幅扩大/收窄**：主体是降幅（绝对值）

**计算对照表**:
| 今年增速 | 表述 | 去年增速 |
|---|---|---|
| 10% | 增速扩大5个百分点 | 5% |
| 10% | 增速缩小5个百分点 | 15% |
| -10% | 增速扩大5个百分点 | -15% |
| -10% | 增速缩小5个百分点 | -5% |
| -10% | 降幅扩大5个百分点 | -5%（去年降幅5%） |
| -10% | 降幅收窄5个百分点 | -15%（去年降幅15%） |

**来源**: 资料分析第0章专门强调，第2讲应用。鹏鹏老师原话：「同样是扩大的一个表达，我们改变了它的主语，一个是增速，一个是降幅，它的结果确实不太一样。」

## I (Intent / 触发)

**触发条件**:
- 题目出现「降幅扩大/收窄」
- 题目出现「增速扩大/缩小」
- 用户需要由今年增速推算去年增速

**用户问法示例**:
- 「降幅扩大5个百分点怎么算」
- 「今年增速-10%，降幅收窄3个百分点，去年是多少」
- 「增速和降幅有什么区别」

## A1 (Application 1 / 标准应用)

**标准流程**:
1. **识别主语**: 判断表述主体是「增速」还是「降幅」
2. **转换符号**: 如果主语是降幅，先把降幅转成增速（加负号）
3. **应用变化**: 增速扩大→减；增速缩小→加
4. **转回表述**: 如果需要降幅形式，再取绝对值加负号

**标准示例**:

*示例1：增速扩大*
> 题目：今年增长率10%，增速比上年扩大5个百分点，去年是多少？
>
> 分析：主体「增速」，今年比去年多5个点
> 计算：去年 = 10% - 5% = 5%

*示例2：降幅扩大*
> 题目：今年增长率-10%，降幅比上年扩大5个百分点，去年是多少？
>
> 分析：主体「降幅」，今年降幅10%
> 计算：去年降幅 = 10% - 5% = 5%，去年增速 = -5%

*示例3：降幅收窄*
> 题目：今年增长率-10%，降幅比上年收窄5个百分点，去年是多少？
>
> 分析：主体「降幅」，今年降幅10%
> 计算：去年降幅 = 10% + 5% = 15%，去年增速 = -15%

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- **vs 增速比较原则**: 增速比较处理「多个值比较大小」，降幅处理「单个值的变化计算」。两者都涉及绝对值概念，但用途不同。
- **vs 百分点**: 任何「x个百分点」都是差值，但主语决定是增速差还是降幅差。

**变体场景**:

*变体1：连续两年变化*
> 今年-10%，降幅扩大5个点 → 去年-5%
> 去年-5%，如果题目还给出去年的降幅变化 → 前年可继续推算

*变体2：增速为负但是「增速扩大」*
> 今年-10%，增速扩大5个点 → 去年-15%
> 注意：这里的「增速扩大」指增速本身变大（-10% > -15%），不是降幅扩大

## E (Example / 示例)

**典型示例**（来自课程）:
> 今年增长率-10%，降幅扩大5个百分点
> - 今年降幅10%
> - 去年降幅 = 10% - 5% = 5%
> - 去年增速 = -5%

> 今年增长率-10%，降幅收窄5个百分点
> - 今年降幅10%
> - 去年降幅 = 10% + 5% = 15%
> - 去年增速 = -15%

## B (Boundary / 边界)

**适用范围**: 涉及增速变化的资料分析题，尤其是负增速场景。

**不适用场景**:
- 增速为正时的「增速变化」题（直接用百分点加减即可）
- 纯概念题（问降幅定义）

**常见错误**:
- 把「降幅扩大」当成「增速扩大」（方向相反）
- 忘记降幅只适用于负增速
- 混淆「增速缩小」和「降幅收窄」（前者增速变小，后者降幅变小）

**与其他知识的关系**:
- 前置知识：ABRX四量（理解R的含义）
- 关联知识：百分点（降幅变化也是百分点差值）
