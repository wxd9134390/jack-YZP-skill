# 增速比较原则 — 增速比较判读规则

## R (Resource / 资源)

**定义**: 资料分析增速比较题的题干判读规则，避免混淆增长量和增长率。

**核心规则**:
| 题干用词 | 比较对象 | 说明 |
|---|---|---|
| 增长**最多/最少**、增加**最多/最少** | **增长量 X** | 「多少/大小」→ 绝对量 |
| 增长**最快/最慢**、增速**最高/最低** | **增长率 R** | 「快慢/速度」→ 相对量 |
| 增幅**最大/最小**、增长幅度**最大/最小** | **增长率 R** | 增益带符号比较 |
| 变化幅度**最大/最小** | **\|增长率\|** | 取绝对值比较 |

**关键区分**:
- **增速/增幅/增长幅度** → 带符号比较（正数 > 负数）
- **变化幅度** → 取绝对值比较（|-20%| > |10%|）

**来源**: 资料分析第0章明确提出，第3-5讲多次应用。

## I (Intent / 触发)

**触发条件**:
- 题目问「增长最多的是」「增长最快的是」
- 题目问「增幅最大的是」「变化幅度最大的是」
- 用户在比较多个选项的增速/增量时卡住

**用户问法示例**:
- 「增长最多和增长最快有什么区别」
- 「增幅最大怎么比」
- 「变化幅度是看绝对值吗」
- 「这道题问的是增长量还是增长率」

## A1 (Application 1 / 标准应用)

**标准流程**:
1. **读题干找关键词**: 定位「多少/快慢/幅度/变化」
2. **匹配比较对象**: 
   - 多少/大小 → 增长量X
   - 快慢/速度 → 增长率R
   - 幅度/增幅 → 增长率R（带符号）
   - 变化幅度 → |增长率|
3. **计算对应指标**: 按匹配的对象计算
4. **排序比较**: 找出最大/最小

**标准示例**:

*示例1：增长最多 vs 增长最快*
> 题目：A增长量10，增长率5%；B增长量8，增长率12%。问增长最多的是？增长最快的是？
>
> 分析：增长最多→比较增长量→A(10)>B(8)，选A
> 分析：增长最快→比较增长率→B(12%)>A(5%)，选B

*示例2：增幅 vs 变化幅度*
> 题目：R1=10%，R2=-20%。问增幅最大的是？变化幅度最大的是？
>
> 分析：增幅最大→带符号比较→10% > -20%，选R1
> 分析：变化幅度最大→取绝对值→|10%| < |-20%|，选R2

## A2 (Application 2 / 变体应用)

**相邻能力区分**:
- **vs 降幅看绝对值原则**: 增速比较处理「比较多个值的大小」，降幅专门处理「单个值的表述变化」。降幅是增速的特殊场景（增速<0时）。
- **vs ABRX四量框架**: ABRX负责计算，增速比较负责判读。先判读问的是X还是R，再用ABRX计算。

**变体场景**:

*变体1：多指标混合比较*
> 同时问「增长最多」和「增长最快」，需要分别计算X和R，然后分别比较

*变体2：伴随百分点变化*
> 「增速扩大了5个百分点」，这属于增速变化的表述，不是比较题
> 处理：用降幅/增速变化的计算规则

## E (Example / 示例)

**典型示例**（来自课程）:
> 一个增速10%，另一个增速-10%。
> - 问增幅最大 → 10% > -10%，选前者
> - 问变化幅度最大 → |10%| < |-10%|，两条一样大（都是10%）

> 一个增速10%，另一个增速-20%。
> - 问增速大小 → 10% > -20%，前者大
> - 问变化幅度 → |10%|=10%，|-20%|=20%，后者大

## B (Boundary / 边界)

**适用范围**: 所有涉及「比较大小」的资料分析题，尤其是增长量和增长率的混合比较。

**不适用场景**:
- 单一数值计算题（不需要比较）
- 纯概念记忆题（直接问定义）
- 百分点变化题（属于增速变化计算，非比较）

**常见错误**:
- 把「增长最多」当成比较增长率（应比较增长量）
- 把「增长最快」当成比较增长量（应比较增长率）
- 把「增幅」和「变化幅度」混淆（前者带符号，后者取绝对值）
- 忽略负号（-20%和20%的变化幅度相同）

**与其他知识的关系**:
- 前置知识：ABRX四量（理解X和R的定义）
- 关联知识：降幅看绝对值原则（增速<0时的特殊处理）
