# bijiao-lei — 比较类（比值大小 / 增量大小 / 替代比较）

> 来源：2026-10-27 补转 `20260701资料分析6.mp4`（比较类）。花生十三/鹏鹏老师体系。

## R (Resource / 资源)

**定义**：资料分析「比较类」专题。与求数类不同，比较类只要比出大小即可，核心是"怎么偷懒怎么来"。三大题型：
1. 比值大小比较（增速、比重、平均数、倍数都可看作分数）
2. 增量大小比较
3. 替代比较（5 种省时技巧）

**五大类全景**：资料分析 = 计算技巧 + ABRX + 比重 + 盐水(混合) + 比较 + 平均倍数（资料分析6讲比较，资料分析7讲平均倍数）。

## I (Intent / 触发)

**触发条件**：
- 题干问「最高/最低/最大/最小/最快/最慢/从高到低/排序」
- 多个选项比大小
- 用户问「怎么快速比大小」「增量谁大」「年均增速排序」「X比B代替」

## A1 (Application 1 / 标准应用)

### 一、比值大小比较（看作分数）
- **趋势法**：分子增速 > 分母增速（R1>R2）则分数变大；分子涨得慢则变小。用 10% 做基准判断快慢。
- **双线法（图示化）**：把 X（分子）与 A（分母）画两条线。分子下降 + 分母上升 → 分数变小；看"距离"长短判大小。
- **王者荣耀法（盐水拆分）**：如 5412 → 5400+27 / 12+1，原胜率 50%，后 12 场只赢 1 场，整体被拉低（<50%）。
- **放缩法**：分母加到接近相同再比分子。
- **拆分法**：接近 1/3、1/2 等特殊分数时直接拆。

### 二、增量大小比较（X 大小）
- **大大则大**：B 越大 R 越大 → X 越大（正 R）；R 为负时，B 越大、下降率越大 → 下降量越大。
- **一大一小看倍数**：我的 B 是你的 N 倍，你的 R 是我的 M 倍；N>M → 前者增量大，N<M → 后者大。
- **追击思想（综合分析）**：高的涨得多 → 差距拉大；高的涨得少 → 差距缩小（顺差/逆差变化判断）。

### 三、替代比较（5 种，仅限比较题，提速）
1. 末期/基期 代替 年均增长率（间隔年数相同，都开方减 1，直接比末期/基期）。
2. B/A 代替 (B-A)/A（B 是 A 好几倍时，减 1 无意义，直接 B/A）。
3. X/B 代替 X/A（只给 B 和 X 无 A 时，增量/现期 代替 增量/基期，大小关系不变）。
4. A/非A 代替 A/整体（男生/女生 代替 男生/全班；出口/进口 代替 出口/进出口总额；受理/未受理 ≥3:1 即受理率>75%）。
5. 高度比 代替 数值比（图表 0 刻度一致时，高度之比 ≈ 数值之比，可转面积比）。

## A2 (Application 2 / 变体应用)

**相邻能力区分**：
- vs ABRX：比较类是 ABRX 的"比大小"应用，不需算准数值，只求大小关系。
- vs beishu-pingjunshu（倍数/平均数/平均倍数）：平均倍数是"求数"，比较类是"比大小"，分工不同但都属比值家族。

**常见变体**：
- 年均增速比较 → 用替代 1（末期/基期），不用开方。
- 比重/平均数/倍数 的比值比大小 → 用趋势法/双线法/放缩。

## E (Example / 示例)

*示例1：趋势法*
> 分子涨 8%、分母涨 3% → 分子涨得快 → 分数变大。

*示例2：替代4（受理率>75%）*
> 「受理/整体 > 75%」转化为「受理/未受理 > 3:1」，省去 6 个大加法。

*示例3：单位换算*
> 1 公顷 = 15 亩（必记）。题干万亩、图表万公顷时先统一再比。

## B (Boundary / 边界)

**适用范围**：所有出现"比大小/排序/最值"的题型。

**不适用场景**：
- 替代比较必须是「比较题」，求具体数值不能用（数值会变）。
- 高度比法要求图表 0 刻度一致，否则变形不可用。
- 一大一小看倍数有极少数反例（增速几百%的极端题），但绝大多数题无碍；若拿不准，用假设分配/415 算两个增量比。
