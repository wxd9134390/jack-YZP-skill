# 四海公考·资料分析速算体系 Skill

## 使命

基于四海公考鹏鹏老师/花生十三2026系统班课程（资料分析第0章+第1-7讲+总结+答疑/总结加课）蒸馏而成。帮助行测考生快速定位数据、识别考点、选择速算方法、准确计算。

## 核心能力

### 能力1：ABRX四量与知二求二

**触发词**：ABRX、基期、限期、增长量、增长率、公式、知二求二

**规则**：
- A=基期值，B=限期值，X=增长量，R=增长率
- 任意知二即可求二
- 基础公式：X=B-A，R=(B-A)/A，A=B/(1+R)，B=A(1+R)

### 能力2：速算方法选择

**触发词**：速算、415分数法、假设分配、化除为乘、包子法

**规则**：
- 增速为负或0-10% → 化除为乘
- 增速0-20% → 假设分配法（推荐）
- 增速与常用分数接近 → 415分数法
- 增速>20% → 直接公式

### 能力3：增速比较判读

**触发词**：增长最多、增长最快、增幅、变化幅度

**规则**：
- 「多少/大小」→ 增长量X
- 「快慢/速度/增幅」→ 增长率R（带符号比较）
- 「变化幅度」→ |增长率|（取绝对值）

### 能力4：高频考点规则

**触发词**：百分点、翻番、降幅、同比、环比、比重、利润率

**规则**：
- 百分点 = 百分数差值；翻N番 = 2^N倍；降幅 = |增速|（仅当R<0）
- 产销率 = 销售/生产；利润率 = 利润/收入

### 能力5：平均数与倍数（平均倍数类前两块）

**触发词**：平均、人均、亩产、平均每场/每件/每笔、是几倍、多几倍、基期平均数、比值趋势

**规则**：
- 平均数=总量/个数；闰年366/平年365（能被4整除，整百年须被400整除）
- 两平均数之比 = 两边除中间 (A×D)/(B×C)
- 基期平均数 = 现期平均数 ×(1+分母增速)/(1+分子增速)（溢价增长率反过来）
- 平均数趋势=比值趋势：R1>R2 上升（定性不算数）
- 平均数增长率 = (R1−R2)/(1+R2)
- **是多少倍 = 多多少倍+1**（2倍=多1倍，10倍=多9倍）
- 基期倍数/比值倍数/间隔倍数：分别用基期比重公式、比值增长率+1、间隔增长率+1
- 详见 references/ziliao/beishu-pingjunshu.md

### 能力6：比值差与第四章综合题

**触发词**：比值差、比重差、均价差、每笔金额、上升下降多少元、综合题、最后一题

**规则**：
- 问「差」= A比B做减法；问「是多少/约多少」= 问量，不是差
- 比值差公式 = 今年的分母分之去年的分子 × 增长率之差（同比重差）
- **比重差能秒杀**（比重<1），**比值差不能秒杀**（比值可>1），直接套公式
- 单位是「元」→ 比值差；单位是「百分号」→ 比值增长率
- 详见 references/ziliao/ronghe-zonghe.md

### 能力7：比较类（比值大小 / 增量大小 / 替代比较）

**触发词**：比大小、排序、最值、增量谁大、年均增速排序、双线法、王者荣耀法、追击思想

**规则**：
- 比值大小：趋势法、双线法、王者荣耀法（盐水拆分）、放缩法、拆分法
- 增量大小：大大则大；一大一小看倍数；追击思想
- 替代比较5法：末期/基期代替年均增速；B/A代替(B-A)/A；X/B代替X/A；A/非A代替A/整体；高度比代替数值比
- 详见 references/ziliao/bijiao-lei.md

### 能力8：线段法 / 盐水思想 / 学习法

**触发词**：线段法、十字交叉、盐水思想、混合思想、人均收入、学习法、马虎

**规则**：
- 线段法=十字交叉图示化；口诀「谁的量(分母)大，谁离混合点近」
- 盐水三适用：增长率、比重、平均数本身（分子分母都能拆）；不适用平均数增长率
- 人均收入 = 比值题：(R1−R2)/(1+R2) 求增速
- 学习法：思维导图复盘 + 费曼输出 + 速算变本能
- 详见 references/ziliao/xuexifa-duanxianfa.md

### 能力9：年均增长量与年均增长率

**触发词**：年均增长量、年均增速、年均增长率、平均每年、十三五、十四五、间隔倍数、格尺法

**规则**：
- 年均增长量 = (末期−基期)/N；**N=末期年份−基期年份（算出来，不是想出来）**
- 年均增长率：末期/基期=(1+R)^N
- 三方法：公式法（选项远）；**格尺法**（背 1.05⁴≈1.22 / 1.1⁴=1.46 / 1.15⁴=1.75 / 1.2⁴=2.07）；近似法 末期/基期≈1+NR（R 极小时，兜底且不准）
- **基期推不推**：十三五/十四五必推；题干「17-20这四年」必推；江苏必推；图表让出第一年建议推；推不了/顶格提问不推
- 江苏「假设年均增速相同求后期」：用年均增速相等搭桥（25年/22年=22年/19年）
- 详见 references/ziliao/yunju-zengzhang.md

### 能力10：答疑易错陷阱 + 速算口诀

**触发词**：易错、踩坑、口诀、公式表、考前、又错了

**规则**：
- 六大陷阱：增长几倍vs是几倍、百分数vs百分点、降幅vs绝对值、平均数增长率分子分母、基期比重用反、翻番倍数
- 速算口诀：ABRX / 增速三问 / 速算三法 / 三兄弟
- 详见 references/ziliao/yicuo-koujue.md
